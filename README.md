# Week 3 Discussion Classification Problem
### For this classification problem, I selected the iris dataset provided by scikit-learn. This dataset has a list of different flower species and their variables. In this problem, I will be classifying the species of the flower using the variables provided. To do this, I constructed a Decision tree that treats the species of flower as the target variable, and the other columns as features that will be used to classify which species it belongs to. We first explore the dataset, showing that sepal length, sepal width, petal length, and petal width are all measured in centimeters (cm). I will use these as our feature variables to predict what type of species the flower is, either Setosa, Versicolor, or Virginica. 
### This model will initially be generated with a maximum depth of 3 and trained using 70% of the dataset, with 30% used for testing; we see that since the dataset contains 150 observations, 105 observations are used for training and 45 observations are used for testing. Further testing will be performed later in the code to see if the maximum depth of 3 is ideal for this data. We will identify that max_depth = 3 achieves a high training and testing accuracy. A maximum depth of 4 and 5 are able to achieve a higher training accuracy; however, they are shown to have a lower test accuracy. This indicates that at these depths, the model is overfitting to the training data. It is identifying patterns that exist within the training data, increasing accuracy, but that do not exist in new, unseen data. 
### Our model at a depth of 3 achieved a training accuracy of 98.1% and a test accuracy of 97.8%, showing that the model is performing well and able to make accurate predictions. To further show how well our model performed beyond an accuracy measure, I show the confusion matrix. This confusion matrix shows how the test predictions are classified and what kinds of errors are made. We can see that only 1 error is made, which is a Versicolor flower incorrectly identified as a Virginica. Finally, I show a plot of the decision tree, which demonstrates the logic used. In combination with the feature importance scores, we see that Petal Length and Petal Width are the two variables used by the decision tree; sepal length and width are not used at any point. Petal Length is shown to be the most important feature in identifying the species of flower by the decision tree, with an importance score of 0.551.
